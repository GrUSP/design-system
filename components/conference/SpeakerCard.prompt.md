A speaker profile card — portrait (composes `Avatar`), name, role/company and talk title.

```jsx
<SpeakerCard
  name="Chiara Salvatore"
  role="Frontend Engineer"
  company="Olo"
  photo={photo}
  talk="Designing for the next billion devices"
/>
```

Pass `photo` for a portrait (initials fallback otherwise). `interactive` adds a hover lift for clickable line-ups.
