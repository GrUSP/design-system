A compact control for a single icon (close, share, menu, social links). Always pass a `label` for accessibility.

```jsx
<IconButton label="Share" variant="outline"><ShareIcon/></IconButton>
<IconButton label="Close" variant="ghost" circle><CloseIcon/></IconButton>
```

Variants: `soft` (grey fill), `solid` (black), `accent` (yellow), `outline` (poster keyline + offset), `ghost`. Sizes `sm`/`md`/`lg`; `circle` for round.
